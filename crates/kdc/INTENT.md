The `kdc` crate implements a simple Key Distribution Center (KDC).
It is used for the Kerberos protocol implementation testing and adding Kerberos support for non-AD environments.

## Specifications

The KDC implementation should follow these specifications as close as possible:

* [RFC 4120: The Kerberos Network Authentication Service (V5)](https://www.rfc-editor.org/info/rfc4120/).
* [[MS-KILE]: Kerberos Protocol Extensions](https://learn.microsoft.com/en-us/openspecs/windows_protocols/ms-kile/2a32282e-dd48-4ad9-a542-609804b02cc9).
